# Security Policy

## Supported Versions

The following versions of SoroCrew repositories currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| dev / main | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within any SoroCrew repository, please report it to our maintainers:

* **Email:** maintainers@sorocrew.org
* **Telegram:** Join [t.me/sorocrew](https://t.me/sorocrew) and contact an admin directly.

Please do not open public GitHub issues for security vulnerabilities. We will respond promptly to investigate and resolve reported issues.
